# Showcase

One file: [`lintel-the-harness.html`](lintel-the-harness.html) — a single-page HTML system map.
Open it in a browser; there is no build step and nothing to install.

It is a poster, not a reference. For the full inventory use
[`skills/CATALOG.md`](../../skills/CATALOG.md) and the generated tables in
[`docs/wiki/`](../wiki/README.md); for how the system actually fits together, read
[architecture](../architecture.md).

## What the page contains

- A title, a one-line tagline, and three counters: skills, agents, packs. These three numbers are
  the only content read from the repository at generation time.
- A **system map** table with five rows — foundation skills, workflow skills, schemas, tools, packs —
  each naming a handful of representative entries. It is a grouping, not an enumeration.
- An **architecture** table of three contracts: the pack manifest (`lib/pack-schema.yaml`), the
  hand-off envelope (`lib/envelope-schema.yaml`), and the meta-infrastructure gates that apply to
  scaffolding changes. The heading above it still carries an older version label — cosmetic drift
  in the template, not a claim about the current release.
- A footer with the generation timestamp and a link to the generator.

That is the whole page. It does not show the nine cycle phases, per-agent detail, or any gap
inventory — those live in [the cycle](../the-cycle.md) and [`docs/wiki/agents.md`](../wiki/agents.md).

## It is a static snapshot

The file is generated by `bin/li-wiki-gen`, which produces `docs/wiki/` and this page from the same
sources. Regeneration is manual and occasional — no continuous-integration job checks that the
committed copy matches the tree, so the page is only as current as the timestamp in its footer.

The copy committed here was generated on 2026-06-12 and reports 124 skills; the tree now has 125.
That gap is the normal state of this file, not a bug to report.

- `bin/li-wiki-gen --check` exits 1 if regenerating would change anything.
- `bin/li-wiki-gen --showcase-only` refreshes just this page.

Hand edits are overwritten on the next regeneration. To change the page, change the sources or the
template inside the generator. See [wiki generation](../concepts/wiki-generation.md) for the
determinism contract and what does and does not regenerate.

## Self-contained

The claim is literal, and worth knowing if you plan to pass the file around:

- All styling is inline. No JavaScript, no web fonts, no stylesheets, no images, no network fetches.
- The only outbound reference on the page is a single hyperlink to the generator's source on GitHub.
- Text renders in whatever monospace font the operating system supplies.

So it works from a USB stick, as an email attachment, or on any static host. One limitation: the
palette is a fixed dark theme with no light-mode variant, which prints poorly.
