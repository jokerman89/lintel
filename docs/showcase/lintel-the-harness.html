Zone 1 · Entry & Mode

§Three entry points feed one harness.

Lintel doesn't care if you're starting fresh, continuing yesterday's work, or jumping into someone else's cwd. The harness rehydrates state automatically, picks a mode envelope, and routes you into the 8-phase cycle.

/li:cycle
Fresh intent — SENSE detects what you mean, picks a phase, opens a new cycle. Bootstraps profile + lessons on first run.
~2.5k tokens · 1-2 min
/li:resume
Continue from .lintel/state/00-state.md — checkpoint integrity verified, phase + intent rehydrated.
~1.2k tokens · 30s
/li:skill-router "intent"
Free-text → top 3 matching skills. The discovery surface when 130+ skills exceed muscle memory.
~1.5k tokens · 30s

Zone 2 · The Cycle

§Eight phases. Each phase reads, gates, writes.

The cycle is Lintel's spine. Every cycle moves through SENSE → CAPTURE in order; phases can be hopped if state lets you. Each phase writes to .lintel/state/00-state.md so the next session knows where you stopped.

1SENSE
Reads
operator message · profile.yaml · 00-state.md · last-2 lessons (via lessons-surface)
Gates
none — pure read
Writes
SENSE report · elephant-hint if breadth-signals ≥3
2DEFINE
Reads
SENSE output · operator's elephant-pick (A/B/C)
Gates
voice-tier resolved · pause if NEEDS_CONTEXT
Writes
problem statement · acceptance criteria · → office-hours if design needed
3DISCOVER
Reads
DEFINE output · codebase (gbrain semantic + grep) · prior runs in ~/.lintel/
Gates
dedicated subagent (rule A) — open-ended; main context stays clean
Writes
research notes · pattern-vault lookup · context-warming manifest
4PLAN
Reads
DEFINE + DISCOVER artifacts
Gates
handoff-size-check (500k cap) · plan-eng-review or plan-ceo-review if non-trivial
Writes
plan.md · task breakdown · agent-mapping · cold-executor prompt
5BUILD
Reads
plan.md · per-task spec · agent-mapping.yaml
Gates
dedicated subagent per task (rule A) · TDD if test files exist · voice gate if customer-share
Writes
code · tests · build-log.md · atomic commits
6REVIEW
Reads
build output · plan.md · CORE-PRINCIPLES · HARD-RULES if WorkProfile=on
Gates
3-stage adversarial (spec → quality → compliance) · dedicated subagent (rule B fresh context)

review-report.md · compliance-report.md · ship-readiness verdict
7SHIP
Reads

compliance-gate aggregator if customer-share · EV2/OneBranch validation · provenance stamp

Zone 7 · Gaps · Honest

§Where Lintel is still incomplete.

Mapping a system honestly means naming what isn't done. These are the open edges as of v3.7.0-dev — some genuinely operator-blocked, some deferred YAGNI, some untapped potential.

Operator-blocked

T0 voice corpus uncalibrated

Customer-share voice gate requires T0 calibrated. Costs $1.80–6 × 3–5 rounds and requires operator's ear-judgment on samples.

→ blocks customer-share output until run
Operator-blocked

Marketplace submission · MS-legal

Plugin manifest ready. Submission to Anthropic + MS marketplace pending internal legal review (human/org process).

→ submission packet preppable now; legal-loop is operator-driven
Soft-finding

Cycle-integration of frontend-design

v3.7 ships solo-invocable and via direct call. BUILD-phase auto-trigger ("frontend output detected → frontend-design fires") deferred to Fas D dogfood validation.

→ unlocks after real-engagement run + L-004 enrichment
Soft-finding

layout_grammar.grid enum implicit

frontend-design-spec.json schema accepts free string but canonical only uses "12-col". Operators extracting may surface "freeform" / "bento" / "asymmetric".

→ document field as free-string in canonical pattern.json
Soft-finding

extraction_confidence rubric not specified

frontend-style-extract emits low/medium/high but the criteria for each band is implicit. Operator left to interpret.

→ add rubric to skill body if dogfood shows interpretation friction
Deferred · YAGNI

SKILL.md DRY pattern (m-2)

9 frontend-* + generate-* skills share orchestrator/sub-skill anatomy. No docs/concepts/frontend-skill-anatomy.md yet. Copy-paste drift risk = low at current count.

→ address when next family adds (cohort 7+)
Deferred · YAGNI

--keep-runs <N> flag

generate-pipeline run-dir grows in ~/.lintel/generate-runs/. Flag specced but not implemented. Operator can manually clean.

→ build when run-dir size becomes friction
Untapped potential

Behavior coverage for ~80 v3 skills (6.9)

build-pilot test is the only behavior test. ~80 older v3 skills have no behavior-test (presence-tests only). Pilot worked; expansion deferred to operator-priority signal.

→ pilot on 3 most-used after operator picks them
Untapped potential

Cross-CLI parity drift risk

instruction-parity-check shipped, but the codex/cursor/gemini/copilot shims are not exercised by CI on every PR. Drift only catches on the next instruction-parity run.

→ add CI step running instruction-parity-check on every PR
Untapped potential

No usage-analytics dashboard

usage-log writes JSONL but nothing renders it. "Top 10 skills this week" / "skills installed but never used" / "override rate per hook" all readable in principle.

→ /li:catalog --usage subcommand or dedicated /li:analytics skill
Untapped potential

gbrain is local-only

Semantic index per-worktree pin works locally. Remote-MCP mode for teams not configured. Teammates can't share index.

→ /setup-gbrain Path 4 (remote-http) document + tooling
Untapped potential

Canonical pattern re-evaluation

L-001 trade-off acknowledged: ultra-modern-lovable-style is canonical content. If operator-extracted patterns > 3 dominate, demote canonical to docs/samples/. No data yet.

→ measure after Fas D real-dogfood
Zone 8 · The Lintel Way

§Four durable lessons.

Lessons that graduated from incident reports in tasks/lessons.md to architecture-level principles in LAYERS.md. They shape what each layer does and what each layer refuses to do.

L-001
Scaffolding, not content
"Ship the structure. Operator-AI generates content at invocation. ⚠ slots are a feature."
L-002
Grep first
"Before designing a new skill family, enumerate existing. 30 seconds beats an entire design backtrack."
L-003
Verify counts
"External docs may be wrong. Run the find before applying any 'truth-fix' from a backlog."
L-004
Separate decisions from execution
"Two families could own a scope. Split by decision/execution, not feature coverage. Schema = contract."

Respect what exists. Respect what doesn't. Verify claims about what exists. Separate decisions from execution.
