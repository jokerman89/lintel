# Structure change: v4.11 launch polish — e2e fail-closed + context-budgetwatch removal

> Gate M1 (structure-impact analysis) artifact. Closes the two structural remainders of the
> State-of-the-Harness §18 punch-list (operator-approved 2026-06-10).

## What changed (shape)

1. **Test-runner semantics** — `tests/runner/run-all.sh` now exits 1 when an explicitly
   requested scope discovers zero test files (fail-closed). Previously `tests/e2e/` was empty
   while the `e2e-claude-code-only` CI job ran green against it — a green job asserting nothing
   (§18 #5 / backlog P1-3). `tests/e2e/harness-critical-path.sh` is the first real e2e:
   install.sh into a sandbox `LINTEL_HOME` → pack-resolver real-parse of `_default`
   (asserts `voice.enforce`, a field outside the hardcoded fallback list) → cycle footer
   rendered from a fixture append-log state. Tagged `claude-code-only` to match the CI filter.

2. **Skill removal** — `skills/context-budgetwatch/` deleted (§18 #6). The v4.9 T19
   consolidation moved the check to `/li:context-budget --watch` and left a thin delegator
   skill behind; this completes the move. The old name resolves via `config/aliases.yaml`
   (`skill_aliases`, grace window to 2026-09-10), following the `match`→`skill-router`
   removal pattern. `install/verify.sh`'s optional budgetwatch probe dropped; references in
   `skills/context-budget/SKILL.md`, `hooks/shared/context-bloat-warn/HOOK.md`, and
   `docs/design/CONTEXT-ENGINE.md` updated/annotated.

## Why (intent)

Both items are the "rough — close before a clean GA" remainder of the readiness assessment
(`docs/lintel-state-of-the-harness.md` §18): a CI surface that promised coverage it didn't
have, and a residual skill the audit had already sentenced. Subtraction bias: the skill
count drops by one; the e2e dir gains its first honest test.

## Compatibility

- `run-all.sh` exit-1-on-empty-scope only fires when a scope has zero tests — all five
  scopes now have ≥1 test, so existing CI jobs are unaffected (and now honest).
- `/li:context-budgetwatch` invocations resolve via the alias dispatcher during the grace
  window; capability is unchanged (`/li:context-budget --watch`). `deprecated-aliases-resolve`
  shape test covers the mapping.
- Skill count: 169 → 168 (CATALOG.md self-regenerates on push to main; README count updated
  in the same PR).
