## What changed (shape)

1. **BUILD spine** — `skills/build/SKILL.md` gains step **3b-guard**: before ANY review dispatch
   (inline or dedicated), the orchestrator verifies the implementer produced a non-empty,
   non-whitespace diff against the task's start ref. Empty diff → review must not run, task
   cannot be DONE, status forced to BLOCKED. Closes Convergent #5 (superpowers #1701: a reviewer
   fed a no-op tree rubber-stamps it). `tests/behavior/build-pilot.sh` asserts the guard's presence.

2. **Hook removal** — `hooks/entropy-secret-check.sh` deleted. Declared by v3.6 cohort 5 item 6.5
   but never wired into any hook event, settings file, or pack (audit P1-7; verified zero
   references outside audit docs). The shipped secret coverage lives in `hooks/shared/`
   (`secret-scan-block`, `no-secrets-in-edit`, patterns in `_patterns.sh`).

3. **Frontmatter-contract doc fix** — CLAUDE.md's frozen-zone line claimed a single contract
   (`layer`, `category`, `cli_support`, `tier`) spanning skills and agents; reality is two:
   skills carry `layer` + `cli_support`, agents carry `category` + `tier` + `cli_support`
   (audit P1-1; verified 0/168 skills carry `category`). Doc now states the real split.
