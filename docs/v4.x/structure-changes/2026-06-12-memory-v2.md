# Structure change: memory-v2

> Gate M1 artifact — ADR-0006.

## What changed (shape)

Three skills removed (aliased: snapshot→save, dump→restore, warmup→warm; grace to 2026-09-12).
One hook added (memory-budget-warn, warn-only). Two shared helpers added (lib/memory.sh,
bin/_context.sh) — the mechanical core for lesson surfacing and context checkpoints. CAPTURE
loses the operator-profile append (dead write) and gains the update-phase classification.
Scaffold emits AGENTS.md + .claude/rules/.

## Backward-compat

Old skill names resolve via config/aliases.yaml (the v3.6 dispatcher). lessons.md format is
unchanged — `superseded_by:` markers are additive. operator-profile.jsonl files remain on disk
(no reader existed; nothing breaks). Digest output adds lines, removes none.

## Migration path

None required for operators. Repos scaffolded pre-v5 get AGENTS.md/.claude/rules on next
`li-scaffold init` run (idempotent) or manually.

## Forward-compat

New memory mechanisms must land as bash helpers (lib/memory.sh) + skill prose that CALLS them
— prose-only memory promises are a regression class now (tests/unit/memory-v2.sh pins the
helpers' existence and behavior).

- full suite green (see PR)
