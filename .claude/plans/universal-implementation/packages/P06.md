## Contract

One surface record per CLI/desktop/IDE/cloud, not one vendor-wide boolean. Retain
current client IDs as compatibility aliases when needed. Each operation records:

- Vendor documentation status/source/date/version conditions.
- Delivered Lintel adapter path/binding or explicit manual fallback.
- Observed scenario status, exact version/revision and evidence; default `not_run`.

Operations cover questions, planning, instructions/skills, file/shell/browser, delegation,
isolation, memory/resume and hooks. Discover actual session tools instead of prescribing
Claude names or models. Native worktrees are change isolation, not a security sandbox.
Without safe parallel write isolation, serialize; without subagents, provide usable
package handoffs/status/restart and retain outstanding independent review.

No invented plugin enable/disable marker or install command. Preserve known client
adapters and offer tested native discovery output only where official paths/contracts
are known. A generic canonical-file handoff is a useful explicit fallback, not native
installation. Do not silently mark all platforms "full" or claim observed support from
the official documentation table.
