**Authority:** A14/A16; CP-03/06/07/08/13/15, AG-03/07/10, existing design ADR0015-17.
**Prerequisites:** P03 URL/recovery, P05 controls, P06 host, P07 profile, P08 work and

Own design/frontend/browser skills and their reference/schema/helper assets:
`design-dna`, `design-consultation`, `design-html`, `design-review`, `design-shotgun`,

`generate-web`, `generate-app`, existing framework generator skills, `plan-design-review`,
`browse`, `open-managed-browser`, `setup-browser-cookies`, `scrape`.
Corresponding frontend agents may change after P09 relinquishes them. Do not take
document renderers, `make-pdf`/`generate-pdf` (P12), central profiles/controls or catalog.
Report P11.md with actual local preview/browser artifacts in gitignored runtime storage.

Preserve design-dna data/provenance, profile precedence, useful motion/type/shader
expertise, extraction/variation modes, runtime/performance evidence, cookie/session
ownership and familiar entry points. No mandatory fashion library or animation.

Use real available browser tool APIs after discovery, not assumed MCP schemas. A synthetic
loopback fixture is authorized; verify a started local server responds and stop that
specific process after the scenario. No personal browser profiles, remote/customer pages
or credential transfer. If a native operation truly is unavailable, preserve a concrete
fallback and leave that observation unverified.

Add `tests/integration/design-browser-pipeline.sh` for actual contract/fixture flow,
and record native browser read/action/print evidence separately. Static source checks
cannot establish layout, accessibility interaction or performance; mandatory unavailable
measurements remain unverified via P05. Recheck low contrast, reduced motion, keyboard
flow and exact schema/argument negatives. Do not fake visual inspection with file size.

Commit coherent code/method/test changes and report actual artifacts, per-leaf outcomes,
profile effects and preserved scenarios. Independent reviewer must not repair the design.
