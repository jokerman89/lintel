## Decision and boundary

Use one internal logical-source boundary pass in `bin/li-copilot.py`. Preserve original
source spans and bytes while representing logical container bodies, visual indentation,
paragraph/container continuity and line termination, including EOF. All reference,
inline and code/exclusion consumers use this same classification.

An optional-title reference definition may end at EOF. Quote/list containers must
preserve residual indentation so code is not mistaken for navigation, and real prose
inside or following a container stays navigable. Keep structured stdlib HTML parsing;
collect literal tag attributes without treating raw script bodies as Markdown.

Do not append a newline to actual source, introduce a new parser dependency, narrow
promised valid syntax, change path/privacy policy or edit shared schemas/other packages.
Remove superseded competing raw-line interpretations instead of adding exception regexes.
Scope remains the owned generator, its nav/consumer tests, directly related client-guide
wording and the P06 report. Shared reducers are coordinator-owned.
