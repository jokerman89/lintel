# P09 agent preservation map

## Authority, inventory and evidence key

The original [69-role audit inventory](../../../engineering/audits/2026-09-20-universal-quality/agents-inventory.md)
is from `28061e434be455ca02f135b73244eaf4f73f3a69`. Every original name/path is retained.
Each role below was read in full at the authorized current base
`56df03d1757b483048e68ac846a3863ff558bb6b`, including accepted P03/P05 corrections,
before editing. That base contains 69 canonical roles and no additional canonical
role outside this original set. No alias, merger, file-count reduction or rename
is used. All native frontmatter, including optional memory/model fields, is preserved.

All rows trace R06/A17.1. Other leaf IDs specify the content advanced, **not completion**.
A17.2 is a body-method adaptation under accepted ADR-0028; native registration/model
bindings are not changed or claimed. A09.3/.4 are knowledge-only. A09.1/.2/.5 and
A17.5 still require coordinator release of the dependency-bound runtime work.

**Verification labels:** D = this implementer's full documentary self-review against
the original inventory/current body; S01 = inventory/name/map coverage; S02 = narrative
mode markers; S03 = distinct role/authority markers; S04 = selected blanket-rule
regressions; S05 = linked domain methods and selected false-claim regressions;
S06 = local-link resolution. E01-E06 are executable **synthetic arithmetic/toy
examples**, not role invocations: percentile composition, contrast, strict/tolerant
enum handling, replay totals, retry/SLO arithmetic and narration time.
Exact runs/exits are in [P09.md](P09.md). These checks cannot establish model judgment,
native discovery, real clients, clinical/legal advice, production behavior or
independent acceptance. Every row retains that boundary; additional specific gaps
are stated below. A row marked retained is a justified no-change, not a skipped read.

N01 is one actual `functions.task` / `general-purpose` source-guided demonstration,
named `p09-narrative-demo`: a synthetic blank six-minute brief produced an arc and
matching narration in one separate actor context. Its actual model ID was not exposed.
It is neither native registration of the canonical role names nor independent review,
live asset inspection, rehearsal or the still-gated A17.5 integration acceptance.

Source links identify the preserved canonical role. Technical provenance is retained
in the role or the five linked domain references; new wording is original synthesis,
not copied proprietary standards. Existing frontend ADR/Anthropic provenance remains.

## Retained expertise and remaining seams

Eight whole bodies remain deliberately unchanged: CodeReviewer, ComplianceOfficer,
DesignSystemAuditor, LatencyAnalyzer, Refactorer, RegressionDetective, SchemaArchitect
and ThreatModelDrafter. Their distinct expertise and accepted predecessor safety/gate
methods are retained rather than restyled for edit volume. All other changes address
specific original findings or their immediate evidence/responsibility implications.
Reviewers still report; implementers repair; retrieval, synthesis and planning remain
separate roles.

The main domain skills receive only links to their new knowledge references. Their
frontmatter, dispatch tables, shell-shaped loops, profile reads, result shapes and
audit writers are deliberately unchanged pending release. Therefore old domain runtime
assumptions are **not** fixed by these role bodies. The eventual A09/A17.5 binding must
consume accepted work/profile/review contracts, pass the actual mode to receivers,
retain mandatory failures and verify interrupted/installed/Windows behavior.

P11 owns later design schema/renderer/browse integration; no-motion or framework-fit
advice here does not prove that every current renderer can serialize or honor it.
P12 owns later document-format adapters and rendering/editability evidence. P13 and
the coordinator own generated discovery/frontmatter presentation: retained native
metadata is not a universal capability or model-selection claim.
