## Delivered contract and API

`lib/cli-tiers.yaml` is the single schema-version-2, JSON-compatible YAML source. It has
38 separate surface records, explicit compatibility aliases, 15 semantic operations and
dated official source/version/condition records. `lib/client_capabilities.py` validates
and consumes it; the shell API and installer use that same reader.

Python APIs: `load_registry(path)`, `surface_id(registry, id)`, `describe(registry, id)`,
`resolve(registry, session)`. The read-only CLI is:

```text
python3 bin/li-client-capabilities.py validate
python3 bin/li-client-capabilities.py list
python3 bin/li-client-capabilities.py show --client <surface>
python3 bin/li-client-capabilities.py resolve --session <session.json>
```

Session schema 1 carries an actual stable `session_id`, exact `surface`, nullable known
`host_version`, `bindings` keyed by operation (`tool`, boolean `available`, and
`permission: allowed|ask|denied|unknown`), plus `isolation` (`kind`, boolean `attributable`,
evidence). Optional `work_map` and the effective-profile owner's `profile_ref` pass through
unchanged. This reader does not implement profile validation.

Selection never executes a tool. Its result explicitly has `executed: false`,
`evidence_level: declared-session-bindings` and `independent_review: outstanding`.
Missing question tools select conversation; denials block and pending/unknown permission
does not fall back around approval. Delegation without attributable isolation selects
serial work; absent delegation selects manual handoff. Missing browser evidence remains
manual/unverified. Absent hook/plugin/model APIs are unsupported, not invented controls.

`bin/li-adapter.py` is only a thin entry into `bin/li-copilot.py`. It reuses bundling,
whole-file/block ownership, safe-path checks, preflight, atomic writes and conflict refusal.
`init --client <surface>` accepts repeated client flags and preserves the installed client
set in the same inventory; `check` verifies that set. `other` is an explicit manual route.
There is no global/model/enable/hook installation flag. Filesystem/user-home roots are refused.

One `.github/lintel/` source bundle serves native wrappers and `.github/lintel/START.md`.
The bundle retains source-relative shim paths as well as legacy bridge aliases, actual
`.claude-plugin/plugin.json` product metadata and the neutral pack schema. Project prose,
knowledge and existing Copilot files survive; modified managed files/blocks are refused.
No private packs, runtime state, accounts, settings or hooks are copied or activated.
