## Traceability method for `git diff --name-only origin/main <head>`

Use the merge base (`origin/main...<head>`) rather than the moving `origin/main`; the merge base of
the head with the current `origin/main` is still `e9401f52`. Then:

1. **File level** (`tools/trace.py`): walk the first-parent chain `base..head` once; for every
   changed path, the last mainline commit that touched it owns its final bytes. A merge owner whose
   second parent carries the same blob means the bytes came from a merged unit branch; otherwise the
   bytes are a merge resolution. A single-parent owner is a direct mainline commit.
2. **Line level** (`tools/blame_scan.py`): `git blame --first-parent` over every changed product file
   attributes each surviving line to the mainline commit that brought it. This finds direct-commit
   content inside files whose final owner is a reviewed merge. Each direct commit is matched to
