### F1 - P1: file-URL normalization verifies a different destination from Git

**Source:** `lib\private_sync.py:45-51`, consumed at `:122-130`, `:191-206` and
`:268-269`. **Affected tools:** roles and lessons. **Confidence:** reproduced.

`urlsplit(value).path` drops a file URL's fragment. Git's local file transport treats
the unescaped `#suffix` as part of the repository pathname. These are not equivalent
normalizations.

Create two bare repositories named `approved.git` and `approved.git#obsolete.git`.
After binding to the first, set `remote.origin.url` to the first repository's file URL
plus `#obsolete.git`. Both `status` and `push` return **0**. The approved repository's
HEAD remains unchanged; the second, unapproved repository gains the newly committed
private record. Both wrappers print `Pushed private ... to the verified origin.`
No config changes occur during the operation.

The same parser affects setup: `setup file:///.../approved.git#obsolete.git` returns
**0** and binds the fragmentless `approved.git`, not the repository Git addresses
with that literal URL. The initial tests covered ordinary rewrites and URL drift,
but not normalization that conflates two real Git destinations.

**Required repair:** use destination equivalence matching the Git transport, or reject
unsupported/ambiguous file-URL forms before enabling or transferring. Do not drop URL
components and call the resulting different path equivalent. Add setup and drift
regressions for both tools, including push-only URL drift and encoded/literal special
characters as applicable. Preserve explicit local/file URL support and optional sync.

### F2 - P1: a failed pull can force-replace the pending local branch and files

**Source:** `lib\private_sync.py:273-277`. **Affected tools:** roles and lessons.
**Confidence:** reproduced, including a default-config control and recovery bounds.

The explicit remote/branch and `--ff-only` do not isolate the fetch phase from
`remote.origin.fetch`. With a valid binding and two divergent commits, set:

```text
remote.origin.fetch = +refs/heads/main:refs/heads/main
```

`git pull` uses an update-head-allowed fetch. The configured mapping force-updates
`refs/heads/main`, then Git updates the index and working tree before the later
fast-forward-only merge fails.

| Observation, for each CLI | Default fetch mapping | Mapping above |
|---|---|---|
| CLI pull exit | 1 | 1 |
| Pending local HEAD retained | Yes | **No: HEAD becomes the divergent remote commit** |
| Pending index tree retained | Yes | **No** |
| Pending record bytes retained | Yes | **No: remote record replaces them** |
| A local branch still contains the pending commit | Yes | **No** |
| Pending commit present in `main` reflog | Yes | Yes |

The observed stderr includes `main -> main (forced update)`, `fetch updated the current
branch head`, and then `Not possible to fast-forward, aborting.` This is a failed
operation that has already changed the state it should preserve, not merely a remote
tracking update. The follow-up fixture changed `# Pending local history.` into
`# Conflicting remote history.` in the cache. The lesson source file is not the file
being replaced.

Recovery remains possible from the retained reflog; this report does **not** claim
immediate permanent object deletion. Nevertheless, the active pending branch/index/
content is lost and an ordinary retry does not restore it. No concurrent editor,
hook, reset or force-push is needed.

The report-contained replay recorded these exact temporary-fixture transitions
(fixture commit IDs are not product revision IDs):

| CLI and state | Before failed pull | After failed pull |
|---|---|---|
| Roles `refs/heads/main` | `d28b9ee7a333936d5eb154b8bf52d633b3da022c` | `d0136bbb0956906913ad64451a377a37bcd851c5` |
| Roles index tree | `102f8d7a014cc84eace4bb73bed80bfd03f64ad3` | `107c2de855698b1b8cf1bc7d01eda797276c599c` |
| Lessons `refs/heads/main` | `0081d28c0ea06c58840580a9edb85549334b40cd` | `a84fd49d6d37dbdef3e463568094a47309230019` |
| Lessons index tree | `c5deb0cdc7017cadee901306599b8a09766c78c9` | `f6d70a97086d48f11e33dc22d659e396551f33a1` |

**Required repair:** reject unsafe fetch destinations before mutation, or perform
fetch with an explicitly controlled refmap/ref namespace and then a separately
verified fast-forward-only integration. Do not inherit a mapping into local branches
or other unowned refs. Preserve the useful default pull path and test divergent
pending commits plus index/content preservation under drifted fetch configuration.

### F3 - P1: raw origin aliases collide despite different effective source repositories

**Source:** `lib\private_sync.py:208-226`, consumed at `:248-261`.
**Affected tool:** lessons. **Confidence:** reproduced.

`project_record()` hashes `git config --get-all remote.origin.url`, not Git's effective
origin. Two source repositories named `project` can both configure the raw origin
`review-alias:project` but have repository-local `url.<different-bare-path>.insteadOf`
rules. `git remote get-url origin` confirms that their actual source repositories
are different.

Push `# Independent project A.` from the first, then `# Independent project B.` from
the second. Both pushes return **0**, produce the **same** `project--<sha256>.md`
filename and leave only one new-format Markdown record. That record now contains B,
not A. The source repositories and prior Git commits still retain their respective
content; the defect is cross-project overwrite of the current synchronized record,
not deletion of the original lesson source.

**Required repair:** resolve and validate the effective fetch origin under each source
repository's Git configuration before deriving identity, or use another explicit
non-colliding stable identity contract. Retain old hash/basename records rather than
silently reassigning or deleting them. Add this distinct-effective-origins case along
with the existing same-origin alias and worktree stability cases.

```python
# p02-local-repro
from contextlib import contextmanager
import json
from pathlib import Path
import runpy

tests = runpy.run_path(str(Path("tests") / "integration" / "private-sync-binding.py"))
failures = []

@contextmanager
def fixture(kind):
    case = tests["RolesSyncTests" if kind == "roles" else "LessonsSyncTests"]()
    case.setUp()
    try:
        yield case, case.fixture
    finally:
        case.doCleanups()

def observe(label, violated, **evidence):
    print(json.dumps(dict(case=label, violated=violated, **evidence)), flush=True)
    if violated:
        failures.append(label)

for kind in ("roles", "lessons"):
    with fixture(kind) as (case, f):
        approved = f.remote("approved")
        obsolete = f.remote("approved.git#obsolete")
        f.setup(approved)
        f.content(b"# Approved original record.\n")
        f.cli("push")
        original_head = f.git(approved, "rev-parse", "HEAD")
        url = approved.as_uri() + "#obsolete.git"
        selection = f.cli("setup", url, ok=None)
        actual = f.git(f.cache, "remote", "get-url", "origin")
        wrong_setup = selection.returncode == 0 and Path(actual).resolve() == approved
        f.cli("setup", approved)
        f.git(f.cache, "config", "--local", "remote.origin.url", url)
        f.content(b"# Must not reach the obsolete destination.\n")
        status = f.cli("status", ok=None)
        result = f.cli("push", ok=None)
        escaped = bool(f.git(obsolete, "rev-parse", "--verify", "HEAD", ok=False))
        observe("F1-" + kind, wrong_setup or escaped,
                setup_exit=selection.returncode, setup_chose_wrong_repo=wrong_setup,
                status_exit=status.returncode, push_exit=result.returncode,
                approved_unchanged=f.git(approved, "rev-parse", "HEAD") == original_head,
                unapproved_received_commit=escaped)

for kind in ("roles", "lessons"):
    with fixture(kind) as (case, f):
        vault, source = f.remote("vault"), f.remote("source")
        f.git(f.project, "remote", "add", "origin", str(source))
        f.setup(vault)
        f.content(b"# Base.\n")
        f.cli("push")
        bob = tests["Fixture"](case, case.base / "bob", kind)
        bob.git(bob.project, "remote", "add", "origin", str(source))
        bob.setup(vault)
        record = f.record(b"# Base.\n")
        record.write_bytes(b"# Pending local history.\n")
        f.git(f.cache, "add", "--", record.name)
        f.git(f.cache, "commit", "-qm", "fixture pending history")
        pending = f.git(f.cache, "rev-parse", "HEAD")
        index = f.git(f.cache, "write-tree")
        bob.content(b"# Conflicting remote history.\n")
        bob.cli("push")
        before = f.state()
        control = f.cli("pull", ok=None)
        control_preserved = f.state() == before
        f.git(f.cache, "config", "--local", "--replace-all",
              "remote.origin.fetch", "+refs/heads/main:refs/heads/main")
        result = f.cli("pull", ok=None)
        head = f.git(f.cache, "rev-parse", "HEAD")
        after_index = f.git(f.cache, "write-tree")
        observe("F2-" + kind, f.state() != before,
                default_exit=control.returncode, default_preserved=control_preserved,
                drifted_exit=result.returncode, head_before=pending, head_after=head,
                head_equals_remote=head == f.git(vault, "rev-parse", "HEAD"),
                index_before=index, index_after=after_index,
                record_after=record.read_text().strip(),
                pending_on_local_branch=bool(f.git(f.cache, "branch", "--contains", pending)),
                pending_in_reflog=pending in f.git(
                    f.cache, "reflog", "show", "--format=%H", "main").splitlines())

with fixture("lessons") as (case, f):
    f.setup(f.remote("identity-vault"))
    source_a, source_b = f.remote("source-a"), f.remote("source-b")
    project_b = f.base / "different-parent" / "project"
    f.make_project(project_b)
    for project, source in ((f.project, source_a), (project_b, source_b)):
        f.git(project, "remote", "add", "origin", "review-alias:project")
        f.git(project, "config", "--local",
              f"url.{source.as_posix()}.insteadOf", "review-alias:project")
    a = f.git(f.project, "remote", "get-url", "origin")
    b = f.git(project_b, "remote", "get-url", "origin")
    f.content(b"# Independent project A.\n")
    f.cli("push")
    record_a = f.record(b"# Independent project A.\n").name
    f.content(b"# Independent project B.\n", project=project_b)
    result = f.cli("push", cwd=project_b, ok=None)
    record_b = f.record(b"# Independent project B.\n").name
    observe("F3-lessons", a != b and record_a == record_b,
            push_exit=result.returncode, effective_origins_differ=a != b,
            record_names_equal=record_a == record_b,
            record_a_after=(f.cache / record_a).read_text().strip(),
            markdown_records=len(list(f.cache.glob("*.md"))))

print(f"ACCEPTANCE VIOLATIONS: {len(failures)}; " + ", ".join(failures), flush=True)
raise SystemExit(1 if failures else 0)
```
