## Mechanism evidence

- **Roster and settings:** `li-mars.py roster` over the host snapshot resolved exactly the
  four models and clamped effort/context per model.
- **Headers:** round-2 requests were rendered by `panel brief` with `round_type: challenge`,
  requester, coordinator, repository/commit, subject, brief hash, model, effort and context.
  Reports with valid headers were parsed into verdict and P1/P2/P3 counts. A mismatched slot
  and MAI's unfenced header were both **refused**, not repaired.
- **Close safety:** close plans listed only this panel's registered, owner-spawned sessions.
  Before archiving, each worktree was verified clean at `28061e4` with no reviewer commits.
  A foreign owner was refused. Eight sessions were archived; no other session was touched.
- **Bugs found by the pilot and fixed:** summary reported `multi_model_verified: true` for a
  partial panel, and `complete` despite a failed challenge report. Both are fixed and tested.

## Operational lessons

1. **Collection:** GPT and Grok ended round 1 with a completion tool and an empty final
   response. One resend request fixed it. The brief now forbids completion tools.
2. **Queued messages** from children reach the coordinator only between turns; read final
   responses from the host session store instead.
3. **Cost:** attempt a2 used ~2.68M input tokens (mostly cache reads) and ~50k output tokens
   over 39 calls for a 20-line subject, because every nested session in this repository loads
   its large instruction set per call. Default transport is therefore `subagent`; use nested
   sessions when the operator wants visible sessions, ideally in a lightweight project.
4. **Format drift is model-specific:** MAI dropped the header fence and repeated a refuted
   claim. Keep header validation strict and let the synthesis carry the failure.
5. **Late queued reports:** attempt-a1 reports sent as cross-session messages arrived after
   their sessions were closed. They are not re-recorded (the a1 panel is closed). MAI's a1
   report shows the same pattern at default effort: it claimed `..\..\app\secret.txt` keeps
   its traversal markers (they are stripped) and that `retry` re-raises on the first failure
   (it never re-raises). Across both attempts, MAI found the right defects with wrong
   counterexamples; the evidence-level rule (P1 needs an executed or traced proof) is what
   catches this.
