## Remaining dissent and the calibration change

`retry` returning `None` was P1 for r1 and r2 and P2 for r3, which read it as a "silent
failure mode". The coordinator adjudicated P1: for error-handling code, the documented
failure behavior is its normal path. The rubric now says so explicitly (method §4, after
this run). No challenge round was run because the consent budget was one round.

## Transport cost

Subagents are not meaningfully cheaper than nested sessions here: 40-71k first-call input
tokens against 45-75k measured for nested sessions on 2026-09-24. Both are dominated by
the repository instructions and tool definitions every child context loads. The default
stays `subagent` because nothing needs closing; the "cheapest" wording was removed.

## Limits

- One run, one synthetic subject; no challenge round.
- Single-review mode was not dispatched live. Byte parity with panel mode is proven by
  `tests/unit/review-method.sh`, so a live single run would have received the same body.
- Device-name and stream semantics were not exercised on a real NTFS open (read-only).
