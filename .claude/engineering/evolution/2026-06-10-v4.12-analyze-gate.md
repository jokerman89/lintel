# Structure change: v4.12 — /li:analyze cross-artifact consistency gate

> Gate M1 artifact. Phase C of the 2026-06-10 initiative; design decided in ADR-0004
> (operator chose "standalone skill" over extend-inline / fold-into-plan-eng-review / defer).

## What changed (shape)

- **New official skill `skills/analyze/`** — read-only three-leg consistency check
  (DEFINE↔PLAN, PLAN↔BUILD, authority alignment) persisting `.lintel/state/analyze-report.md`
  with a GREEN/YELLOW/RED advisory verdict and P1/P2/P3 findings table. Carries the ADR-0003
  cycle-position footer like every official entry point. Catalog: 168 → 169 skills (self-regens).
- **PLAN Step 8 became a delegation** — the inline "Cross-section-analyze" checklist
  (`plan/SKILL.md:156-164`, the partial spec-kit adoption) is replaced by an invocation of
  `/li:analyze --trigger plan-step8`. The operator gap-decision protocol (defer / add / accept)
  is unchanged. Single implementation per shared-schema discipline.
- **BUILD final pass gained the missing leg** — Step 6 now invokes
  `/li:analyze --trigger build-final` after the test suite: every plan task terminal, no
  untasked work shipped, deviations reflected back. Advisory, surfaced to the operator.
- **`tests/shape/analyze-gate-wired.sh`** — regression guard: skill contract pieces present,
  PLAN delegates (and the old inline checklist is GONE — duplication tripwire), BUILD calls
  the build-final leg, ADR Accepted.

## Why (intent)

Convergent #6 from the 2026-06-09 audit ("spec-kit's biggest steal"). Verified before building:
PLAN Step 8 already covered the plan-time leg, so the genuine gaps were re-runnability, the
PLAN↔BUILD leg, a persisted gateable artifact, and authority re-checks — ADR-0004 records the
alternatives and the cost accepted (one more skill; advisory-not-blocking verdict).

## Compatibility

- No state-schema change: the report is a new file under `.lintel/state/`; `00-state.md` is
  read, not written.
- PLAN/BUILD behavior changes only at their next invocation; no helper or hook touched.
- The verdict is advisory by default; a pack may harden it via `compliance.hooks` later.
