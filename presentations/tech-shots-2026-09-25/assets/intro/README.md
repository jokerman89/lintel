# Living portal intro media

The portal animation was supplied by Johannes Åkerman for the Lintel presentation. It is included unchanged: six seconds, 1672 × 942 pixels, silent playback. The poster is a still frame extracted from that supplied video. These are atmospheric illustrations, not evidence of product behavior.

Video SHA-256: `880068378e258bb1ef20abca0c82b6b03a154e923b457cd5571cac0b610e95c6`.

The welcome slide loops the video while attendees join. It is untimed; Begin opens the original first story slide. Pause/play is available, reduced motion starts with the still image, and an unavailable or blocked video leaves navigation usable. Theme changes preserve the media state. Leaving the slide releases playback; hidden tabs pause it. The media is included in the public offline package.
