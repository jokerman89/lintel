11You are the PACK-CREATE skill — scaffolds a new pack in `<repo>/packs/<name>/` or `~/.lintel/packs/<name>/`.
12
13## What this skill does
14
15Creates a new pack directory + manifest. Three modes:
16
17- **Blank pack:** starts from `packs/_default/pack.yaml` skeleton (every field declared with neutral value)
18- **Extending pack:** starts from `packs/_default/pack.yaml` + sets `extends: <parent-name>` (validates parent exists)
19- **Cloned pack:** copies an existing pack as a starting point (operator edits per their needs)
20
21## When to use
22
23- Operator wants a new pack for a fresh customer/team/domain
24- Sister pack to an existing pack (extends: shared parent)
25- Forking an existing pack for an isolated experiment

77### Step 5 — Write manifest
78
79```bash
80mkdir -p "$target_dir/$name"
81cp "$template" "$target_dir/$name/pack.yaml"
82
83# Replace name: line
84sed -i.bak "s/^name: .*/name: $name/" "$target_dir/$name/pack.yaml"
85rm -f "$target_dir/$name/pack.yaml.bak"
86
87# Add extends: if requested
88if [ -n "$extends" ]; then
89 # Insert after `version:` line
90 awk -v ext="$extends" '
91 /^version:/ { print; print "extends: " ext; next }
92 { print }
93 ' "$target_dir/$name/pack.yaml" > "$target_dir/$name/pack.yaml.tmp"
94 mv "$target_dir/$name/pack.yaml.tmp" "$target_dir/$name/pack.yaml"

128## Integration
129
130**Reads:**

132- `lib/pack-resolver.sh` (validation)

134**Writes:**
135- `<scope>/packs/<name>/pack.yaml`

138**Triggers (recommends):**
139- `/li:pack-switch <name>` to activate the new pack
140- `/li:pack-list` to confirm
141
142## Anti-patterns
143
144- **Creating a pack to override one field** — edit `pack.yaml` of an existing pack instead
145- **Not validating extends parent** — broken extends silently degrades to _default at runtime
146- **Auto-activating after create** — operator decides when to switch (avoids surprise behavior changes mid-session)
