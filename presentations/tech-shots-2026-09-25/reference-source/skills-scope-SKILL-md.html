197## Integration

199**Reads:**
200- operator's last message (the request)
201- `.claude/runtime/state/00-state.md` (SENSE's orientator route — `intent_detected`)
202- `lib/scale-estimator.sh` (the size axis — Slice 1; SCOPE sources it, never edits it)

209**Triggers (recommends, never auto-invokes):**
210- DEFINE next (inherits `chosen_reading` as the wedge)
211- PLAN later reads `scope.depth_schema` to select the WBS template variant

213## Anti-patterns
214
215- **Asking when the request is clear** — the gate fires ONLY on `scale_amb=yes`. A confident XS/S/L runs silent.
216- **More than one question** — exactly one AskUserQuestion, max, per invocation.
217- **Doing DEFINE's job** — SCOPE sizes + disambiguates; it does NOT run forcing questions, premise checks, or alternatives. That's DEFINE.
218- **Blocking on degraded AskUserQuestion** — fall back to the mechanical conservative size + note the assumption; don't halt the cycle.
219- **Editing the estimator** — SCOPE *sources* `lib/scale-estimator.sh`; it never modifies the lib (other slices own it).
220- **Emitting wall-clock time** — size + est_tokens only, unless `--with-time` (design §3.7).
