11# /context-save
12
13Save the current session's load-bearing state to a checkpoint file so a fresh session can resume cold. Use **before** context bloat hits productivity, OR when handing off to a teammate, OR when ending a session mid-task.
14
15## When to use
16

30 - Current branch via `git branch --show-current`
31 - SLUG via `_context_repo_slug` from `bin/_context.sh` (native — basename of the repo root; no external binary)
32 - Recent uncommitted work via `git status -s` + `git diff --stat HEAD`

38## Workflow
39
401. Resolve slug + branch + timestamp.
412. Compute the checkpoint path via the mechanical core (`bin/_context.sh` owns naming + directory creation; checkpoint CONTENT stays LLM-written):
42
43 ```bash
44 source "${LINTEL_SOURCE_ROOT:-$LINTEL_REPO_ROOT}/bin/_context.sh" # fallback: "${LINTEL_SOURCE_ROOT:-$(git rev-parse --show-toplevel)}/bin/_context.sh"
45 path=$(context_save_path [label])
46 ```
47
48 `context_save_path` echoes `.claude/runtime/sessions/<branch>/<YYYYMMDD-HHMMSS>-<slug>[-<label>]-context-save.md` and creates the directory. The filename ends `-context-save.md` so `/context-restore` and `/context-warm-sessions` globs match.
493. Gather:
50 - **What the task is** — one-line description (operator-provided or inferred from recent turns).
51 - **What got done** — bulleted from todo-list completed items + recent commit messages on this branch.
52 - **What's in-flight** — active todo items + dirty git tree summary.
53 - **What's next** — top 1-3 next steps.
54 - **Decisions taken** — surface any AskUserQuestion answers from the session (operator-noted).
55 - **Failed attempts** — patterns/approaches tried that didn't work (so next session doesn't re-try).
56 - **Files touched** — `git diff --name-only HEAD` + any uncommitted-but-staged files.
574. Write the checkpoint content to `$path` with this structure:

117## Edge cases
118
119- **No git repo:** still save, but `branch` field is `no-git`. Slug derived from cwd basename.
120- **No `.claude/runtime/sessions/<branch>/`:** `context_save_path` creates it.
121- **Existing checkpoint with same timestamp:** suffix with `-2`, `-3`, etc. Never overwrite.
122- **Operator pastes recent turns inline:** capture them verbatim under a `## Recent turns (operator-pasted)` section.
123
124## Compliance integration
125
126This skill writes a checkpoint outside the committed tree (to the gitignored `.claude/runtime/sessions/`). Per Lintel Layer 2:
127- The checkpoint file may contain references to in-flight work that touched files in the repo. Operator confirms NO customer-data is captured in the checkpoint before saving.
128- Default sanity-grep before write: if the checkpoint text matches secret-shaped patterns, halt and surface to operator.
129
130## Failure modes
131
132- **Write fails (disk full / permission denied):** report error, print checkpoint content to stdout so operator can copy it manually.
133- **Slug resolution fails:** fall back to `unknown-project`.
