333**Writes:**
334- the scope-routed `envelopes-<date>.jsonl` (per-envelope audit)

338For v5-layout repository work, the routed directory is `.claude/runtime/audit/`. An explicitly set
339`LINTEL_AUDIT_DIR` overrides that destination; work without a migrated repository falls back to
340`~/.lintel/audit/`. The runnable sequence above and these write declarations use the same unified
341router from `bin/_audit.sh`.
