LINTEL / FIELD GUIDE

Run the demonstrations

These browser demonstrations are prepared artifacts. They do not call a model or a cloud service.

Same prompt. Two builds.

  1. Open the build lab. Start with the visible results.
  2. Open each dashboard in its own tab. Try customer selection, the view filters and available export controls.
  3. Open Same brief to inspect the common task and answers. Then use Why it changed to inspect the decisive steps.
  4. Open Evidence and read the actual checks and limitations. A tie is a valid outcome.

Baseline dashboard · Lintel dashboard

Profile, cold handoff and a regression

Open the helper proof explorer. Switch profile, inspect the saved handoff and compare the failing and passing regression variants. These are saved executions from pinned helpers; clicking replays evidence rather than running a live agent.

Run offline

Download and unzip the public kit. Open index.html in a modern browser. If your browser restricts local iframes, run python -m http.server 8000 inside the unzipped folder and open http://127.0.0.1:8000. Repository links and external research need an internet connection; the presentation and synthetic dashboards do not.

Repeat the evaluation with your own agent

Use the recorded protocol, shared answers and curated treatment as an example. Pin your client and model versions, give both conditions the same knowledge, tests and permissions, run independent repetitions, and include overhead. The planned Lintel Benchmark distribution is not bundled here.
