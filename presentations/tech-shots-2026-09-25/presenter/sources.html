What the demonstrations show

The prepared comparison uses synthetic data and real local implementations. Both arms receive the same task, fixture data, stakeholder answers and test/CI contract. One also receives curated workflow context. There is one run per arm. The final comparison does not mix in the superseded attempt.

Read the protocol, input provenance and results. The helper explorer shows saved deterministic executions; it runs no model behind the page. No remote CI run or general productivity gain is implied.

The swarming moment: personal activity

Johannes supplied these two original GitHub contribution-graph crops and identified them as before and after adopting Lintel swarming: 55 contributions on June 12 and 711 contributions on September 4. The files are reproduced unchanged. The crops show no year.

These are two selected personal activity observations. Task mix, time spent and other conditions are not controlled. Contribution count is neither a count of bugs fixed nor a measure of accepted changes, quality or productivity. No causal effect or general speedup is established by the images.

The report-remediation flow illustrates the swarming execution contract: opt-in execution with one coordinator, dependency-ready work in isolated scopes, independent lane reviews and final integration checks. MDASH and MARS are examples of report sources named by the presenter, not claims of native integrations. Parallel execution requires host support and attributable isolation; otherwise replay the briefs sequentially.

Reading this site correctly

Catalogue entries describe source content. They do not certify execution across every host. Workflow instructions are distinct from enforced permissions, CI and platform policy. Planned Core, CAIP pack and Benchmark distribution links will be added later; those packages are not included in this site.

Curated example plans, specs, questions and handoffs are demonstration evidence. Public speaker notes are prepared delivery text. Raw session transcripts, private company packs and authoring work files are excluded.
