Questions worth asking

Is this a new model or hosted agent?

No. Lintel supplies reusable method, project knowledge and specific helpers inside existing clients. The host controls execution and permissions.

Does Universal mean feature parity?

No.37 named surfaces plus fallback describe a registry.25 records have native-format routes. Delivered discovery, vendor capability and observed execution are separate. Inspect the matrix.

Does Copilot have hooks?

Yes, according to the vendor documentation recorded in the source. Lintel has not translated its Claude-protocol hook bundle into Copilot hooks. The Universal repository kit installs none.

Why127skills if the goal is about 80?

127 is the current source count. About80 is a planned consolidation target: fewer overlapping entry points while preserving useful capability. Counts are not outcome evidence.

Did Lintel win the kitchen test?

No completed three-arm comparison is published. The new test measures Service House in Naked Copilot, Lintel serial and Lintel+Swarming. Reference100/100 is calibration only.

What changed between the arms?

Naked-versus-Lintel changes workflow and delegate-model mix. The two Lintel arms keep version, delegate configuration and review policy the same; parallel package execution is the intended difference.

What happens without native subagents?

Use a documented serial or external handoff. Missing isolation prevents concurrent writes. A missing independent reviewer leaves review open; self-review is not independent evidence.

What proves the review still applies?

Structured evidence binds to selected content, original acceptance and effective profile. Content changes stale clearance. A later applicable rejection overrides older pass evidence. This does not cryptographically prove reviewer identity.

Does more process always help?

No. Use a small default core and proportionate verification. Measure accepted outcomes and overhead; retain the possibility that a simpler setup wins.
