# Memory

Cross-session memory. Lives across sessions; updated as understanding accumulates.

Different from `lessons.md`: lessons are **rules I do not want to violate again** (born from a correction). Memory is **context I want to recall** (the operator, the project, the stakeholders, the external systems).

Different from `.claude/plans/todo.md`: todo is ephemeral, scoped to one task. Memory survives across tasks.

Review at session start. Update when something changes — not at the end of every task.

---

## How to use this file

Add entries to the relevant section below. Keep entries:

- **Short**: one to three sentences. If you need a paragraph, write a memory file in a subdirectory and link it.
- **Dated**: include the date you wrote it so stale memories are easy to find.
- **Sourced**: if it came from a conversation, note the date. If it came from a document, link the document.

Drop entries that no longer apply. Do not amass.
